# AI Intrusion Detection System

AI-powered Intrusion Detection System developed for CPSC 491-03.

The project is being developed as a local and web-based system that combines network monitoring, threat detection, backend services, and a browser-based monitoring interface.

## Frontend Technology Stack

The current frontend uses:

- React
- TypeScript
- Vite
- React Router
- npm

## Frontend Local Setup

### Prerequisites

Make sure the following are installed:

- Node.js
- npm
- Git
